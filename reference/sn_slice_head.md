# Limit a lazy ShennongData query

Limit a lazy ShennongData query

## Usage

``` r
sn_slice_head(x, n = 6L, ...)
```

## Arguments

- x:

  A
  [ShennongData](https://zerostwo.github.io/shennong-data/reference/ShennongData.md)
  handle.

- n:

  Maximum number of observations requested per feature.

- ...:

  Reserved for compatible methods.

## Value

A lazy
[ShennongData](https://zerostwo.github.io/shennong-data/reference/ShennongData.md)
handle.
